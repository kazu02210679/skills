# Complexity-Aware Execution

調査・実装・検証の深さを、作業の難易度とリスクに合わせるSkillです。小さな変更は小さく検証し、失敗や矛盾が見つかったときだけ探索範囲を広げます。

## 使う場面

- コード修正、バグ修正、テスト追加
- リポジトリ調査やローカル設定変更
- 調査しすぎと確認不足の両方を避けたい作業

## 入力と出力

- 入力: 変更要求、対象ファイル、既知のエラーや制約
- 出力: 最小限の調査範囲、早い検証、必要な場合だけ拡張した実装結果

## 判断の軸

`Estimate → Execute → Expand` の順で進めます。セキュリティ、権限、秘密情報、破壊的操作、production変更、広いrefactorでは探索を意図的に狭めません。

# Monitoring Subagents

複数のサブエージェントを並行実行するときに、担当、状態、最新の根拠、
介入要否をコンパクトに見える化するSkillです。

## 利用場面

- 2つ以上のサブエージェントが同時に動く
- 長時間タスクで、停止や失敗を早めに把握したい
- 「誰が何をしているか」「介入が必要か」を確認したい
- 複数セッションをまたぐ作業の見える範囲を整理したい

## 判断の軸

ホストが確認できる状態と実際の成果物だけを根拠にします。無更新を失敗と
決めつけず、単発の短いタスクではダッシュボードを作りません。思考ログでは
なく、状態変化と次のアクションを表示します。

## 現在の実装

手順と状態契約は `SKILL.md` に集約しています。常駐プロセスや外部サービスは
不要で、CodexとClaude Codeそれぞれのネイティブな状態確認手段を利用します。

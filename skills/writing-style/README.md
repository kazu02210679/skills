# Writing Style

日本語の説明文を、正確さと情報量を保ったまま読み進めやすくするSkillです。単に文を短くするのではなく、観察・仮説・保留・確定の切り替わりを整えます。

## 使う場面

- 技術記事、解説、エッセイ、章構成の推敲
- 内容は正しいが平板、機械的、読みにくい文章
- 冒頭、段落のリズム、列挙、結論の診断

## 入力と出力

- 入力: 日本語の草稿、対象読者、残すべき事実と制約
- 出力: 根拠を増やさず、必要な前提を落とさない改稿

## 評価方法

事実、話題、問い、文の拍、段落密度、節境界、文脈の順で点検します。読み味のために数値、引用、因果関係を作りません。

## 現在の実装

推敲原則と診断表は `SKILL.md` にあります。文章品質は機械判定しにくいため、SkillOptより人間レビューを優先します。

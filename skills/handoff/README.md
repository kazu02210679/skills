# Handoff

長くなった会話や作業を、新しいタスク・スレッド・セッションへ安全に引き継ぐSkillです。逐語録ではなく、目的、判断の変化、制約、失敗、成果物、次の行動を残します。

## 使う場面

- 「別タスクへ引き継いで」「新しいチャットで続けたい」
- 会話を切り替えても決定事項と未解決事項を失いたくない
- 実装状態や検証結果を、根拠となるファイルやPRと結び付けたい

## 入力と出力

- 入力: 継続目的、移動先、保持すべき履歴と成果物
- 出力: 自己完結したMarkdownの引き継ぎ、または対応ホスト上の新しいタスク

## 制約

ユーザーが長さに言及しただけでは移動しません。観測できない成果物や識別子を推測せず、不明点として残します。

## 出典

初期版は `tegnike` のCodex Session Handoff Skillを基にしています。ライセンスと固定hashは `third_party/handoff-gist/` にあります。
